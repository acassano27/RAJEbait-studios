# Dragonquest

Standalone browser edition of the Arcade adventure. The original Python game remains available as `dragonquest.py`.

## Run locally

From the repository root, start a static web server:

```bash
python -m http.server 8000
```

Open <http://localhost:8000/dragonquest/>.

Use the arrow keys or WASD to move. On touch screens, use the direction pad. Reach each dungeon through the matching door in Waystone Hall, collect all three chalice shards, and find the sword in Crystal Cavern to defend yourself from dragons.
