# RAJEbait Studios

Minimal game center homepage prototype.

## Run locally

Open the project directory in a browser or serve it with a local web server:

```bash
python -m http.server 8000
```

Then visit:

- http://localhost:8000/
- http://localhost:8000/games.html
- http://localhost:8000/codebreaker/

To play Codebreaker directly, open the game URL above after starting the local server.
Game-specific instructions are in [codebreaker/README.md](codebreaker/README.md).

## Included

- Minimal landing page
- Category navigation
- Clickable sign-in modal
- Local user tracking with game history stored in `localStorage`
- Empty collection page ready for future game additions
